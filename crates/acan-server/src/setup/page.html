Model keys

acan calls each model provider with a key you give it. A key is checked with its own provider only, and kept in a file that only your user account can read. A key is never shown again and never sent anywhere else.

Providers

Add a key for each provider you use. A key is used only for that provider.

Roles

Each role uses the provider you pick. Default takes the first provider with a key that can serve it.

Until a role has a provider, its model jobs get built-in replies, labelled as offline. Back to acan
