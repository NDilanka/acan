Model keys and roles

  
acan calls your model provider with a key you give it. The key is checked with that provider only, and saved in acan's config folder for your user account. It is never shown again.

  

  

    
Roles

    
Each role uses its default provider unless you pick one. Only a provider with a key can be picked.
